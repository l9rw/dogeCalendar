下载最新版本 查看源代码 ↗

前往 GitHub Releases，选择适合你系统的安装包。

WINDOWS + MACOS

两种桌面，同样顺手。

针对不同系统的使用习惯设计入口；月历、农历、天气与世界时间，在两个平台都能使用。

Windows

从任务栏时钟打开日历面板，不打断当前工作；快速查看月历、农历与节假日，右键还能进入设置。

任务栏时钟入口节假日 / 调休标记日期详情
Windows 11 桌面合成展示；应用面板来自真实浏览器预览截图。

macOS

从菜单栏图标展开日历面板，点按空白处即可收起；可调整菜单栏图标样式，保持桌面整洁。

菜单栏图标入口菜单栏样式设置点按外部收起
macOS 27 桌面合成展示，非 macOS 实机截图；应用面板来自浏览器预览。
